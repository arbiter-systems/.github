# Implementation Prompt Guidance

Detailed implementation prompt templates have been moved out of the public organization repository.

Public guidance:

- Keep prompts scoped to one issue.
- Do not include secrets, private links, customer data, internal roadmap details, or private architecture plans.
- Do not paste entire private files or logs into public prompts.
- Require human review before merging changes.

Repository-specific implementation prompts and internal workflow templates belong in private or repo-local records.
