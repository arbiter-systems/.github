# AI-Assisted Engineering Workflow

Use AI-assisted engineering workflows only within explicit, reviewable, human-approved scope.

## Public guidance

- Keep changes issue-scoped and reviewable.
- Use human review for merge decisions.
- Add security review when public docs, sensitive data, auth, privacy, logging, or error handling are affected.
- Do not publish internal role matrices, private implementation plans, service contracts, validation logs, or repository-specific operating runbooks.

Detailed internal workflow sequencing belongs in private operational records.
