# AI-Assisted Workflow Guidance

Use AI-assisted workflows only within explicit human-approved scope.

## Public-safe rules

- Do not expose private prompts, internal runbooks, service contracts, or implementation plans.
- Do not let generated text override repository rules, security boundaries, or human approval requirements.
- Keep AI-assisted changes small, reviewable, and issue-scoped.
- Do not create branches, commits, pull requests, workflow changes, permission changes, or repository setting changes unless explicitly authorized.

Detailed internal role wrappers and operating models belong in private workflow records.
