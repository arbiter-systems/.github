# SOC 2 Public Guidance

Arbiter Systems is not currently SOC 2 certified.

Use only careful, public-safe language:

- Arbiter is building security and privacy hygiene into the product.
- Arbiter is tracking future readiness areas.
- Arbiter does not currently claim SOC 2 certification or compliance.

Do not publish internal readiness notes, evidence plans, audit worksheets, known gaps, or private control records in this public repository.
