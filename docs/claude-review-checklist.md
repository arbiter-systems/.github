# Public Review Checklist

Use this checklist for public repository documentation and metadata changes.

## Review checks

- Content is public-safe.
- Claims are accurate and supportable.
- No secrets, private links, customer data, internal roadmap details, service contracts, local validation logs, or security-gap records are exposed.
- Scope stays limited to the requested issue or PR.
- Human review remains the final merge gate.

Detailed internal review rubrics belong in private workflow records.
