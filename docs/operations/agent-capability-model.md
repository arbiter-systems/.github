# AI Capability Guidance

Detailed agent capability and automation authority models have been moved out of the public organization repository.

Public guidance:

- AI-assisted work must stay within explicit human-approved scope.
- Generated content must not override repository rules, security boundaries, or human approval requirements.
- Do not publish internal authority matrices, project-field rules, automation runbooks, permission models, or escalation procedures.

Keep public guidance high-level and safe for external readers.
