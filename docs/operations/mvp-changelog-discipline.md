# Changelog Guidance

Detailed MVP changelog discipline has been moved out of the public organization repository.

Public guidance:

- Keep changelog entries concise and understandable.
- Do not publish private roadmap details, internal service-contract changes, local validation evidence, security-gap records, or unreleased implementation sequencing.
- Use public-safe release language only when the underlying behavior is implemented and approved for disclosure.

Detailed changelog rules belong in private operational records or repo-local guidance.
