# Project Operating Guidance

Detailed GitHub Project operating models have been moved out of the public organization repository.

Public guidance:

- Keep issue and PR work scoped, reviewable, and traceable.
- Use public-safe labels and templates for external-facing coordination.
- Do not publish internal project-field schemas, views, automation rules, backlog routing, private milestones, or operating runbooks.

Detailed project operations belong in private operational records.
