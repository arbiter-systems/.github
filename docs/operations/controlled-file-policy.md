# Controlled File Guidance

Some repository paths can affect public content, automation behavior, security posture, or repository governance.

## Public guidance

- Review changes to templates, workflows, public profile content, security policy files, and repository guidance carefully.
- Keep changes small and issue-scoped.
- Do not publish internal runbooks, permission details, project configuration, security evidence, or private validation records.
- Human review remains required before merge.

Detailed controlled-file rules belong in private operational records.
